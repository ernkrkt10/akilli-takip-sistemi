# Akıllı Takip Sistemi

Kronik rahatsızlığı olan bireylerin ve yaşlıların hastane randevularını, ilaç saatlerini ve semptomlarını takip etmelerine yardımcı olan akıllı bir web uygulamasıdır. Sistem, kullanıcılara veya yakınlarına SMS bildirimleri gönderirken doktorlar için randevu öncesinde özet sağlık raporları oluşturur.

**Geliştirici Ekip:** Eren Korkut, Rabia Hatice Beyhan ve Osman Berk Cerit
**Kullanılan Teknolojiler:** Python, PostgreSQL (detaylandırılacak)
